# 전동기 학습용 시뮬레이터

타여자·분권·직권·복권(가동/차동, 장분권) DC 전동기의 원리, 정상상태 특성, 동특성, 속도 제어를
파라미터를 바꿔 가며 확인하는 Streamlit 앱입니다.

## 실행
```bash
pip install -r requirements.txt
streamlit run app.py      # 브라우저에서 http://localhost:8501
pytest -q                 # 해석해 비교 테스트
```

## 구조
| 폴더 | 내용 |
|---|---|
| `core/` | 파라미터 정의(ParamSpec), 단위 변환, 이벤트 구간별 solve_ivp 시뮬레이션 엔진 |
| `motors/winding.py` | 3상 권선 배치 (분포권·집중권, 단절권, 분포·피치·권선계수) — 단면·3D·전개도가 함께 사용 |
| `ui/structure3d.py`, `ui/winding_diagrams.py`, `ui/structure_tab.py`, `ui/pages/structure.py` | 전동기 구조 페이지: 3D 구조(회전·분해/조립·부품 이름), 권선 전개도, 결선도 |
| `motors/` | `MotorModel` 공통 인터페이스, 등록소(registry), `dc/` DC 전동기 모델, `bldc/` BLDC 모델, `ac/` 유도전동기·PMSM 모델 |
| `control/` | PI(안티와인드업), 초퍼 평균값 모델, 게인 추천, 이중 루프 속도 제어 |
| `concepts/` | 정류자 토크 파형, 단면 애니메이션 |
| `ui/` | 파라미터 입력 자동 생성, 결선도·블록도, 탭별 화면 |
| `ui/pages/` | 메뉴 페이지: DC·BLDC·유도전동기·PMSM 시뮬레이터, 전동기 구조, 제어 블록 편집기 |
| `ui/realtime/` | 브라우저에서 도는 실시간 시뮬레이터 (engine.js: 전동기·제어기, charts.js: 흘러가는 그래프, structure.js: 전동기 그림, blocks.js + editor.html: 제어 블록 편집기) |
| `tests/` | pytest 검증 |

## 새 전동기 추가 방법
1. `motors/<계열>/xxx.py` 에 `MotorModel`(DC 는 `DCMotor`) 을 상속한 클래스를 만들고 `@register`
2. `param_specs()` 로 입력 파라미터 선언 → 파라미터 입력 영역은 자동 생성
3. DC 여자 방식은 `kphi`, `field_ss`, `R_arm`, `line_current`, `input_power`, `losses`,
   `derivatives` 만 구현하면 정상상태·곡선·동특성이 공통 코드로 동작

## 제어 블록 편집기
메뉴 **제어 실습 → 제어 블록 편집기**. 신호원·합산점·게인·리미터·적분기·필터·P/PI/PID·초퍼·DC 전동기·스코프 블록을
끌어다 이어 제어 구조를 만들고 실시간으로 돌립니다. 템플릿: 이중 루프, 전류 루프만, 속도 루프만, P 제어, 개루프, 위치 제어.
BLDC 전동기 블록(6스텝 인버터 포함)과 BLDC 템플릿 3종, 유도전동기 블록(벡터/V·f 입력)·PMSM 블록(dq 전류 입력)과
교류 템플릿 3종(유도전동기 V/f, 유도전동기 벡터 제어, PMSM 벡터 제어)도 있습니다.
만든 구조는 브라우저에 자동 저장되고 JSON 으로 내보내기/가져오기 할 수 있습니다. 엔진 검증: `tests/test_js_blocks.py`.

## BLDC 전동기
메뉴 **BLDC 전동기 → BLDC 전동기 시뮬레이터**. 3상 Y결선, 사다리꼴 역기전력, 홀 센서 6스텝(120° 통전),
평균값 PWM 인버터와 환류 다이오드 정류 과정을 고정 스텝(10 µs) 으로 계산합니다.
- ① 원리: 실시간 애니메이션 (2극 등가 / 실제 P극 구조, 홀 센서, 인버터 스위치 ON/OFF, 6스텝 통전표, 역기전력·상전류·토크)
- ② 정상상태: 평균 모델(DC 등가, K = 2ke) vs 3상 시뮬레이션, 1주기 파형과 토크 리플
- ③ 동특성: 기동 → 부하 인가 → 듀티 변경, 홀 센서 오차
- ④ 제어: 실시간 속도 PI → 토크 전류 제한 → 전류 PI(+2ke·ω FF) → 듀티 → 6스텝 인버터
검증: `tests/test_bldc.py` (평균 모델 해석해, 기동 전류 Vdc/2R, 홀 정류 순서, JS 엔진과 파이썬 일치).

## 교류 전동기
- **유도전동기** (메뉴 교류 전동기 → 유도전동기 시뮬레이터): αβ 자속 모델(동특성)과 상당 등가회로(정상상태).
  ① 실시간 회전자계·슬립·회전자 유도 전류 ② 토크–속도(발전/전동/제동), 최대·기동 토크, 역률·효율, 전력 흐름, V/f 곡선, 2차 저항 영향
  ③ 직입·Y-Δ 기동, 부하 인가, 주파수 변경 ④ 실시간 V/f(슬립 보상)·간접 벡터 제어(IFOC, 약계자)
- **PMSM** (메뉴 교류 전동기 → PMSM 시뮬레이터): 매입형 dq 모델.
  ① 실시간 FOC (dq 축, 전류 벡터) ② id–iq 평면(전류 원, 전압 타원, 등토크, MTPA)·토크–속도 한계
  ③ 계통 직결: 기동 실패·제동 권선 라인 기동·부하각·탈조 ④ 실시간 FOC (id=0 / MTPA / 약계자, 비간섭)
- 검증: `tests/test_ac.py` (동적 모델 = 등가회로, 최대 토크 공식, MTPA 해석해, 기저 속도 전압 한계, 탈조 토크, JS 엔진 일치)

## 배포 참고 (Streamlit Cloud)
Streamlit 은 코드가 갱신돼도 이미 불러온 하위 모듈을 서버 재시작 전까지 그대로 씁니다.
`app.py` 맨 앞의 `_refresh_project_modules()` 가 소스 변경을 감지해 프로젝트 모듈을 다시 불러오므로
자동 업데이트 후에도 재부팅 없이 새 코드가 적용됩니다. 패키지 버전은 `requirements.txt` 에 검증한 버전으로 고정했습니다.

## 구조 보기 (왼쪽 메뉴 '전동기 구조': DC · BLDC · 유도전동기 · PMSM)
- 3D 구조: 마우스로 회전·확대, 부품에 마우스를 올리면 이름과 역할, 범례로 부품 숨기기, 절개 보기, 분해·조립 애니메이션
- 권선 전개도: 분포권(q, 단절권 피치)·집중권, 상대 배치, 전류 방향, 분포·피치·권선계수
- 결선도: Y/Δ 와 단자함 연결판, BLDC 인버터·홀 센서 연결, DC 전기자 중권/파권과 정류자 연결, 계자 결선
- 구조 페이지에서는 극수·권선 방식·여자 방식을 그 자리에서 고릅니다. 시뮬레이터의 실시간 그림은 파라미터 설정의 '구조 (그림용)' 값으로 실제 구조 단면을 그립니다.

## 회로 시뮬레이터 (왼쪽 메뉴 '회로 실습')
부품(전원·3상 교류 전원·3상 인버터·저항·전구·인덕터·커패시터·스위치·PWM 스위치·다이오드·DC 전동기·전류계·전압계·접지)을 격자 위에 놓고
전선으로 이어 회로를 만들면 브라우저에서 바로 계산합니다 (`ui/realtime/circuit_engine.js`, `circuit.html`).
- 계산: 수정 절점 해석(MNA) + 후진 오일러, 다이오드·스위치는 켜짐/꺼짐 상태 반복. 전선마다 전류는 접점별 KCL 로 나눔
- 표시: 움직이는 점(전류 방향·크기), 부품별 전류 값, 전선 색(전압), 계기의 순시값·실효값, 부품별 전류·전압·속도 그래프
- 예제: RL·RC 과도 현상, 직렬·병렬, RLC 공진, 반파·전파 정류, 3상 Y 부하, 3상 인버터(사인파 PWM·6스텝), DC 전동기 기동 저항, 강압 초퍼
- 검증: `tests/test_js_circuit.py` (RL·RC 시정수, 분배·분류, 공진 전류, 정류 최댓값, 전동기 정상상태, 초퍼 평균 전압, 전선 전류 KCL, 단락 감지)

## 강의 실습 (왼쪽 메뉴 '강의 실습 (모터제어)')
강의 자료 1~4장의 내용을 장별 페이지·절별 탭으로 직접 바꿔 가며 확인합니다. 계산은 `lectures/ch1~4.py`, 화면은 `ui/pages/lecture_ch1~4.py`.
- 1장: 자기회로 λ-i 특성(포화·공극)·에너지/코에너지, 직선 운동 기계의 힘, 릴럭턴스 토크와 동기 조건, 이중 여자 기기 평균 토크 조건(ωm = ωs ± ωr), 부하 종류·운전점·기동, 기어·직선 부하 등가 관성, 엘리베이터 4상한 운전
- 2장: 전압·계자 제어와 능력 곡선, 과도 응답(극점·감쇠비, 교재 140 V 25 A 3000 r/min 전동기 ζ = 0.37), P·I·PI 와 보드 선도, PI 전류 제어(극점-영점 상쇄·전향 보상·누적 방지), 속도 PI·IP·혼합(α), 1상한·H-브리지 바이폴라/유니폴라 PWM
- 3장: 사다리꼴/정현파 역기전력과 전류 모양별 토크 리플, 홀 센서 6스텝(인버터 도통 경로), 스위칭 단위 BLDC 시뮬레이션(상전환 리플, PWM 기법 5종), 센서리스 영점 검출
- 4장: 회전자계 애니메이션(평형·불평형·단상), 등가회로·전력 흐름, 토크–속도·안정 운전점·동작 모드, 2중 농형, 정수 측정(무부하·구속 시험), 속도 제어 방법·속도 영역, 동기 전동기 페이저도·토크각·V 곡선
- 회로 시뮬레이터에 'H-브리지 초퍼' 부품과 예제 추가
- 검증: `tests/test_lectures.py` (해석해·기존 모델과 비교)
